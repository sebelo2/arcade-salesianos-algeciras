# Web del Proyecto Arcade · Chuleta del equipo web

Esta carpeta es la web. Cada archivo `.md` es una página. Cuando guardáis un cambio, la web publicada se actualiza sola en uno o dos minutos.

## Qué archivo es cada página

| Página de la web | Archivo |
| --- | --- |
| Inicio | `index.md` |
| El proyecto | `proyecto.md` |
| Los juegos | `juegos.md` |
| Cada juego | `juegos/juego-1.md`, `juegos/juego-2.md`, `juegos/juego-3.md` |
| La máquina | `maquina.md` |
| E-waste | `ewaste.md` |
| Equipo | `equipo.md` |
| Créditos y licencias | `creditos.md` |
| El menú de arriba | `_data/menu.yml` |

**No toquéis** `_config.yml`, la carpeta `_layouts` ni la carpeta `assets` sin hablar antes con el profesor.

## Editar una página en cuatro pasos

1. Abrid el archivo y pulsad el lápiz (**Edit this file**).
2. Escribid. Con la pestaña **Preview** veis cómo quedará.
3. Pulsad **Commit changes…**. En el mensaje: vuestro nombre y qué habéis cambiado. Ejemplo: `Lucía: texto de la portada`.
4. Pulsad otra vez **Commit changes**. Esperad un par de minutos y recargad la web.

## Markdown en una tabla

| Escribís | Sale |
| --- | --- |
| `## Título de sección` | Un título de sección |
| `**negrita**` | **negrita** |
| `*cursiva*` | *cursiva* |
| `- elemento` | Una lista con viñetas |
| `1. paso` | Una lista numerada |
| `[texto](https://enlace)` | Un enlace |
| `![descripción](imagenes/foto.png)` | Una imagen |
| `> texto` | Un recuadro destacado |
| Una línea en blanco | Un párrafo nuevo |

## Las tres reglas que no se rompen

1. **Las rayas `---` del principio de cada archivo no se borran.** Lo que hay entre ellas son los datos de la página (su título).
2. **Nombres de archivo en minúsculas, sin espacios ni tildes:** `maqueta-panel.jpg`, no `Maqueta Panel.JPG`.
3. **Privacidad:** solo nombres de pila. Ni apellidos, ni caras reconocibles, ni datos personales.

Si algo se rompe, no pasa nada: GitHub guarda todas las versiones. Avisad al profesor.
